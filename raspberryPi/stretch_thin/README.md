_Stretched Thin_ is a kinetic that mimics the human experience of being stretched thin by many pressure inducing factors in life. As strings pull from different direction, a latex face in the center is distorted and stretched thin, then springs back in a collapsing motion to its original state at a certain threshold of stress, evoking the experience of mental stress and burnout. 

Before running this code, make sure you have the Servo library installed in Arduino. Run this code witha a correctly wired servo and stepper motor. Match the GPIO pins in the code to your own wiring.
